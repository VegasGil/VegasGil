- **Detection Engineering:** desarrollo, validación y documentación de reglas de detección con KQL y mapeo continuo a MITRE ATT&CK.
- **Threat Hunting y DFIR:** análisis de telemetría, correlación de IoCs y recolección forense con Defender XDR, Live Response y Velociraptor, incluso en entornos aislados de Internet.

- **Automatización:** flujos de SOC con Python, n8n y triggers en Microsoft Sentinel.
